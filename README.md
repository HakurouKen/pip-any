# Pip Any

## 安装与使用

1. 在桌面版 Chrome 116 或更新版本打开 `chrome://extensions/`，开启开发者模式，点击「加载已解压的扩展程序」，选择已构建的 `dist/` 目录。
2. 将 Pip Any 固定到工具栏，打开普通 HTTPS 网页。
3. 点击插件图标，再点击「选择内容」。移动鼠标预览高亮区域，单击目标锁定选区。
4. 用滑块调整范围：向右扩大、向左缩小；也可按 `↑ / →` 扩大、`↓ / ←` 缩小。
5. 点击「确定」打开画中画浮窗；点击「重新选择」更换目标。

- **取消选择**：按 `Esc`、点击页面提示区「取消」，或在插件面板中点击「取消选择」。已有浮窗不受影响。
- **替换内容**：重新点击「选择内容」，选定新目标并点击「确定」。
- **使用浮窗**：可调整窗口大小，内容超出时可滚动；关闭浮窗后，内容恢复到原页面。

iframe 及包含 iframe 的区域不可选；「确定」禁用时，请缩小范围或重新选择。源页面刷新、导航或关闭后，浮窗结束。
