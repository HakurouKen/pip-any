# 自测指南

本文提供可选择的自测方法。是否执行、执行哪些场景及验证到什么程度，由执行模型根据改动和风险判断，不设每次修改都必须执行的检查清单。

## 选择验证方式

- 文档调整：可检查格式、相对链接、文档归属及前后描述的一致性。
- DOM 逻辑或恢复流程调整：可运行相关测试，按影响范围决定是否执行完整检查。
- 交互、注入或画中画调整：真实浏览器有助于验证用户激活、权限、执行上下文及原生控件行为；根据修改内容挑选下面的场景。

## 自动化检查

在根目录运行 `pnpm test` 可执行现有测试，`pnpm check` 是完整检查入口。各脚本的具体组成以 [package.json](../package.json) 为准。

现有测试使用模拟 DOM，画中画 API、安全上下文和部分窗口生命周期由测试替身提供。它们能验证层级调整、选区锁定、节点搬移与恢复等逻辑，但不能证明：

- Chrome 工具栏点击、临时页面访问权限和真实内容脚本注入链路可用。
- 浏览器认可实际用户激活，或浮窗使用原生关闭按钮后能正确恢复。
- 原生滑块拖动、真实页面导航、外链样式加载及视觉效果符合预期。

合成事件和直接设置滑块值，也不等同于真实鼠标拖动。

## CRX 打包验证

涉及打包流程时，可按 [开发维护](development.md#打包-crx) 执行 `pnpm pack-crx`，检查命令成功退出、产物为 CRX3，且包内包含 manifest 和所需脚本。私钥应留在包外。

可重复打包，比较签名公钥或扩展 ID，确认复用同一密钥。还可按改动检查浏览器路径无效、指定私钥缺失等失败场景：应以非零状态退出，并保留已有产物和密钥。

打包成功只证明生成了签名文件，不代表目标平台允许直接安装，也不代表扩展运行链路已验证。

## 真实扩展验证

先构建，再按 [安装说明](../README.md#安装与使用) 加载实际 `dist/`，通过工具栏图标打开 popup，再点击「选择内容」。重载方式见 [开发维护](development.md#环境与构建)。

可检查 popup 是否在正常页面提供选择按钮，在选择模式中显示「取消选择」，在浏览器内部页或访问被拒绝时显示原因；单纯打开面板不应切换选择状态。

选择普通 HTTPS 网页作为测试页面。[示例页](../examples/index.html) 提供计数器、输入框和链接，可放到已有 HTTPS 测试环境中；直接通过文件或普通 HTTP 地址打开，不符合插件当前入口的支持范围。

按需要选择场景：

1. **锁定与范围调整**：单击目标后应显示滑块，浮窗尚未打开；移向提示区时选区保持稳定。原生拖动滑块往返调整，再用四个方向键调整，检查高亮、滑块值和层级一致，单次按键只变一级，到边界后停止。
2. **取消与重选**：锁定后按 Esc、点击「取消」或插件图标，目标应仍在原页；点击「重新选择」后可重新悬停选择其他目标。
3. **用户激活与搬移**：真实点击「确定」，检查出现原生 PiP 窗口，内容与最终选区一致，原位置保留占位。验证链路时使用实际工具栏入口和正式权限配置。
4. **状态与原生关闭**：在搬移前输入笔记、增加计数；移入浮窗后继续操作，再用窗口关闭按钮关闭。检查输入内容和累计计数保留，原位置、样式与按钮恢复，占位清除。
5. **替换与取消**：已有浮窗时重新选择，取消应保留旧内容；确认新选区后，旧目标回原页、新目标进入浮窗。最后关闭，检查新目标也恢复。
6. **点击拦截**：选择模式中锁定链接，检查源页 URL 未变化、页面点击操作未触发；随后取消选择。
7. **原容器消失**：将示例卡片搬入浮窗后，在源页删除其原容器，再关闭浮窗。检查卡片出现在页面底部并显示中文提示。测试完刷新页面恢复素材。
8. **页面生命周期与限制**：按改动需要检查刷新、导航、关闭源页，以及受限页面的提示和重试；确认没有遗留选择框或占位。
9. **iframe 禁选**：悬停示例中的 iframe 或包含它的外层卡片，检查红色斜纹虚线框、禁选说明与禁止光标；点击不应锁定、打开浮窗或触发 iframe 内部按钮。锁定普通子元素后，用滑块和方向键扩大到含 iframe 的父区域，“确定”应禁用；缩小后恢复。退出选择后检查选择层和标记消失，原 iframe 的加载次数和内部状态未改变。
10. **动态新增 iframe**：选区锁定后加入 iframe，检查禁选反馈更新；即使在窗口创建的等待期间新增 iframe，也不应搬移目标或影响已有浮窗内容。
11. **浮窗自适应**：选择带 padding、边框和固定宽高的卡片，打开后调整窗口宽度，检查外层填满窗口、卡片宽度跟随窗口且文字重新排版；高度随内容变化，超出时仍可滚动。检查视频、图片及 SVG 的比例，并在关闭后确认原页面尺寸与样式恢复。

## 证据与结果

汇报实际运行的命令、浏览器场景、结果和未覆盖部分即可。直接将构建脚本注入页面主世界，只能提供脚本级证据；验证完整扩展入口还涉及工具栏、权限及实际内容脚本执行上下文。

以下为已有验证记录，不代表后续修改自动通过：

- UI 模板拆分通过 Oxfmt、Oxlint 类型感知 lint、类型检查、63 项模拟 DOM 测试及生产构建；因 pnpm 的运行前依赖检查尝试重建现有依赖目录，本次使用 `node_modules/.bin/` 中已安装的对应工具直接执行，未重装或修改依赖。新增覆盖控件存在性、唯一性、标签与输入类型、跨文档归属、动态文本、多实例引用和模板资源约束；popup 测试检查外链 CSS 契约，模拟 DOM 禁用 CSS 文件加载，不据此推断样式已加载。
- UI 模板构建产物检查确认 content 可作为普通脚本解析，无动态 import 或模板资源加载路径，HTML/CSS 文本包含于产物中，popup CSS 与源文件一致。Chrome for Testing 152 已加载实际 `dist/`，直接打开扩展 popup 页面检查了外链 CSS 加载、按钮颜色和受限页面提示；这不是工具栏 popup 验证。
- UI 模板在本地示例页主世界运行构建脚本后，真实鼠标锁定按钮、方向键单步扩大且滑块保持焦点、原生滑块拖动至 iframe 禁选范围及确认按钮禁用均已检查；360 × 240 下提示区保持在视口内并可内部滚动。原生工具栏读取连续超时，未覆盖正式工具栏到隔离内容脚本的完整链路；本次也未验证真实 PiP 打开与关闭。未扩大扩展权限。
- popup 与选择提示区蓝色样式改动通过格式、lint、类型检查、52 项模拟 DOM 测试及生产构建。无头浏览器中检查了使用静态状态的 popup，以及本地预览页主世界运行构建脚本后的锁定提示、方向键扩大至 iframe 禁选区域及缩小恢复；360 × 640 窄屏布局正常，360 × 240 下提示区保持在视口内并可滚动。本次不覆盖正式扩展工具栏入口、隔离世界注入或原生画中画窗口。
- 浮窗自适应改动通过完整检查，包含 51 项测试及生产构建；模拟 DOM 检查了宽高约束、外层滚动与关闭后的样式恢复。本次未验证真实 PiP 窗口缩放、布局及滚动条表现。
- 移除 iframe 支持后，完整检查通过，包含 50 项测试和生产构建；CRX 0.2.1 已验证包结构、popup 入口、权限及捕获 API 清理。
- 本地示例页主世界注入构建脚本后，真实鼠标悬停及点击 iframe 已验证红色斜纹、禁止光标、无法锁定且内部按钮不触发；iframe 文档未更换、加载次数不变。真实方向键扩大到含 iframe 的父区域时确认按钮禁用，缩小后恢复。此记录不覆盖实际扩展工具栏入口或原生滑块拖动。
- Node.js 26.10.0、pnpm 11.24.0 下的完整检查曾通过，包含 29 项测试和生产构建。
- Chrome for Testing 152 中曾验证正式扩展可加载；在 HTTPS 页面主世界运行构建脚本时，验证了锁定、原生滑块拖动、方向键同步、确认打开 PiP、目标搬移与占位。
- 初版真实 PiP 文档中曾验证直接绑定的事件与计数状态保留，窗口退出后节点恢复且占位清除。
- 上述脚本级记录不覆盖工具栏到隔离内容脚本的完整链路。此前原生工具栏自动化接口超时，额外站点权限测试方案被自动审批拒绝后已撤销，没有据此扩大正式扩展权限。
