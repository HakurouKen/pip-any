# Pip Any 术语表

将用户选中的网页元素放入浏览器画中画浮窗。

## Language

**工具栏面板（Popup）**：
点击浏览器工具栏中的插件图标打开的操作面板，用于开始或取消选择。

**选择提示区（Selection panel）**：
源网页中辅助选择目标的操作区域，显示当前范围、相关提示和确认操作；不是画中画浮窗。

**选择模式（Selection mode）**：
用户通过鼠标悬停预览目标，并可调整目标范围的交互状态。

**目标元素（Target element）**：
用户准备放入浮窗的网页元素，范围包含其内部内容。

**浮窗（PiP window）**：
展示目标元素的浏览器画中画窗口。
_Avoid_：页面内弹层
